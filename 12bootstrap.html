COMO INCLUIR BOOTSTRAP EN HTML

TEORÍA BÁSICA

Bootstrap es el framework de CSS de código abierto más utilizado en el desarrollo web front-end. Permite construir interfaces adaptables y responsivas de forma rápida a base de componentes y clases prefabricadas. Se puede vincular a un archivo HTML mediante dos formas principales: descargando sus archivos locales directamente en el proyecto, o conectándose a sus servidores en línea a través de redes de distribución de contenido digitales denominadas CDN.
