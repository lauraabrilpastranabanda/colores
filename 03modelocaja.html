Práctica: Modelo de Caja (Box Model)

1. Introducción Teórica

El Modelo de Caja es la base del diseño web en CSS. Cada elemento HTML se representa como una caja rectangular. Esta caja se compone de cuatro partes esenciales de adentro hacia afuera: el contenido (content), el relleno (padding), el borde (border) y el margen (margin). Comprender cómo interactúan estas propiedades y cómo afecta box-sizing al tamaño final es crucial para estructurar cualquier sitio web.
