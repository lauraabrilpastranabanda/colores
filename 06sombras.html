SOMBRAS EN CSS

TEORÍA BÁSICA

Las sombras en CSS permiten añadir efectos de profundidad tridimensional a los elementos planos de una página web. Contamos con dos propiedades principales: text-shadow, que se aplica directamente a las tipografías para simular relieves en las letras, y box-shadow, que proyecta sombras alrededor de las cajas contenedoras. Para configurarlas, definimos coordenadas de desplazamiento horizontal, vertical, el nivel de difuminado y el color de la sombra.
