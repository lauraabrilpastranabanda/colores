Práctica: Bordes en CSS

1. Introducción Teórica

Los bordes en CSS son las líneas que delimitan el perímetro del modelo de caja, situándose entre el padding y el margin. Para configurar un borde se utilizan tres propiedades esenciales: border-width para el grosor, border-style para el tipo de línea (sólida, discontinua, punteada) y border-color para el color. Además, la propiedad border-radius permite redondear las esquinas de cualquier caja e incluso transformarla en un círculo perfecto.
