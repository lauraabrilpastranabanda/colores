GRID EN CSS

TEORÍA BÁSICA

CSS Grid Layout es el sistema de diseño bidimensional más potente de CSS. A diferencia de Flexbox, que trabaja en una sola dirección, Grid nos permite organizar el contenido tanto en filas como en columnas al mismo tiempo. Es ideal para crear estructuras de páginas completas y complejas, permitiéndonos definir rejillas con tamaños fijos o flexibles y controlar los espacios usando la propiedad gap.
