FLEXBOX EN CSS

TEORÍA BÁSICA

Flexbox o El Modelo de Caja Flexible es un sistema de diseño unidimensional en CSS. Está diseñado para organizar elementos en filas o columnas de manera eficiente. Su principal ventaja es la capacidad de distribuir el espacio disponible de forma dinámica, permitiendo alinear y centrar componentes de manera muy sencilla mediante propiedades aplicadas a un contenedor padre.
